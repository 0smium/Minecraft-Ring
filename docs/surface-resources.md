# 地表基础资源第一版

2026-10-14，Fabric 0.3.5 候选，优先于地下挖矿实施。已有 ER Bridge 世界也能使用，不需要重建存档。**代码和离线检查已完成，尚未启动游戏验证生成位置、合成画面和实际采集。**

## 内容与玩法

| 资源 | 实现 | 用途 |
| --- | --- | --- |
| 橡树、少量桦树 | 4–5格树干、普通树叶，小树模板 | 原木、木板、工作台、木工具；树叶沿原版规则掉树苗/苹果/木棍 |
| 蒲公英、虞美人 | 稀疏小花丛 | 采集、染料 |
| 矮草 | 小片普通矮草 | 原版概率掉小麦种子 |
| 甜浆果 | 少量成熟浆果丛 | 食物、采收后原版再生长 |
| 露天石堆 | 小块普通石头，部分石堆含1块煤矿 | 木镐采圆石、石工具、熔炉；煤/木炭供火把与燃料 |

使用MC原版方块、物品、掉落表、合成和随机刻，不添加替代采集货币或无限领料命令。树叶保留衰败，按树干连通距离初始化，不使用永久树叶。植物有少量可见的原版土/草基座；砍树后可在土上种回树苗。树苗正常长大与骨粉使用原版逻辑，长大后的树冠目前不再向原生法环申请净空，因此紧邻原生建筑种树仍需实机观察。

这里新增的是MC资源，不把法环现有大树、草花直接变成可砍对象。地下石层、洞穴、铁/金/钻石矿脉和完整农田/生物分布尚未实现。

## 自动生成与保存

仅 ER Bridge 主世界、本机法环宿主处于有效MC接管状态时运行，默认开启。确定性16×16格候选每格有65%概率的小树、两处草花候选、少量浆果或石堆；实际还要通过地表筛选。位置取决于世界种子、法环区域、稳定坐标锚点，和探索顺序无关。

检查玩家21格范围内的候选，至少离玩家6格，树冠也落在24格普通地形采样范围内。中心需两次稳定原生采样，整个占地必须已观测、接近平坦、上方采样没有碰撞、没有已知移动支撑。树干/树冠完整包围盒要为空气，不能替换玩家方块、现有植物或液体；不会请求加载新区块，也不会在玩家/敌人身上放树。每秒至多请求一个候选的缺失地表补采，复用原调度器、2048射线批次和原生2毫秒帧预算；不删除旧碰撞或反复清空稳定证据。初到区域不会立刻铺满远景，走动或短暂停留后逐渐具备生成证据。

每半秒至多落下一处完整资源，候选查找有数量/时间预算；一株小树的写入作为一个有界操作完成。生成失败会回滚方块及原精细碰撞NBT，并停用自动生成供检查。精细碰撞缓存重放已加普通MC方块保护，不能把生成树干/花草写回隐形地形。

普通方块存入正常MC区块；完成标记保存在世界的 `data/erbridge_surface_resources.dat`。砍完、重采样、切区、死亡或正常保存重进都不会重新生成同一候选。浆果再生长、自己种的树苗长成属于原版生长，不是生成器补货。关闭后也保留已生成内容；没有清空标记或强制补货命令。

管理员命令（仅本机宿主）：

```text
/erbridge resources status
/erbridge resources off
/erbridge resources on
```

`status` 报告开关、已完成候选数、有效采样数与最近状态。记录类型缺失/格式不兼容时停止新增，不按空账重新刷。

## 首版限制与集中验证

现有射线能判断开阔、坡度和碰撞，尚不能准确区分草地、石路、露天屋顶或静止平台；40米上方射线也不是整张地图的天空证明。先在普通野外地面检查分布；不宣称全地图生态/室外识别完成。水面若未进入原生碰撞射线，也不能仅凭虚空世界的MC空气排除，水边是明确待验项。观察到不合适的位置时可关闭新增，后续补材质/区域筛选。

开启可选 `-NativeBlockCollision` 时，原木/树叶和其他普通MC方块一起参与现有512盒上限；默认关闭时没有这部分原生开销。不要将该实验的开关与资源是否能采集混为一谈。

下一轮由用户集中验证：普通野外走动→看到树花与石堆→砍树做工作台/木镐→采石做石工具/熔炉→采花、草与浆果→等树叶衰败/种回树苗→正常保存退出MC再进，确认采过的原始资源不补回。顺便观察门口、坡地、水边和原生场景遮挡；没有观察到的项目继续记待验。

相关代码位于 Core 的 `dev.ermc.bridge.world`，不依赖 Character、Skills、LB 或 Meteor。复用地表采样与有限补采，不增加射线协议、单批/单帧预算或DLL偏移；自定义调试过滤器启用时停止资源生成。
