# B02 首个角色操作候选

沿[当前架构](architecture.md)推进真实背包观察、MC 马和调试实例归属。此切片已构建并离线检查，尚未实机验收；不代表 B02 全部完成。版本、制品与日志见[2026-10-14 记录](experiments/2026-10-14-b02-character-slice.md)。原规划 PR #2 的文档已汇入当前集成分支。

当前仍在单个 `erbridge` 模组里；下一批必须拆出独立构建/加载的角色 Fabric 模组，并复用原版容器/槽位做可操作的装备附加页。下面只读页与管理员马命令是现有候选，不代表独立模组或最终正常玩法入口已完成。状态与 PR 顺序见[当前开发](current-development.md)。

## 法环背包只读页

在 ER Bridge、本机集成服务器和 MC 接管状态下按 **I** 打开，Esc 关闭；按键可在 MC 设置里修改。页面显示当前携带物品的类别、原始物品 ID、数量及已装备位置，支持分页、搜索、已装备和关键物品筛选。暂以真实 ID 展示，物品名称、图片、装备/卸下/使用操作未接入；没有伪装成可用的操作按钮。

读取真实 `PlayerIns → PlayerGameData → EquipGameData → EquipInventoryData`。检查当前 exe 的九段访问指令、RTTI、owner、活动列表、容量与重复读取一致性；读取失败显示不可用，真实空背包与不可用分开。只遍历活动 length，不把容量尾部残留算作物品；数量为 0 的已拥有物品仍可显示。装备位置同时核对原生槽索引和物品 handle，不能只按相同物品 ID 猜装备。

独立 `HINV v1` 位于共享内存 `0x360000`，64 字节头加最多 1024 个 32 字节条目。原生普通/关键列表各最多读 4096 槽；超过输出条目数时显式标记截断。页面筛选只作用于已收到的条目，不承诺搜索未发送部分。仓库不是本页范围。

完整读取最多每 500 ms 一次，加载、死亡或角色/生命周期变化立即清空旧内容。Java 检查 seqlock、布局、角色指纹、宿主启动时间、生命期和样本时效；面板不暂停游戏，也不发送物品写入。保留原始 ID 的高位类别与低位参数值，不推断强化武器名称。

## MC 马管理员试用

本切片使用真正的原版 `Horse`，不是法环托雷特，也没有另写马的运动/碰撞系统。入口要求权限 2、桥接世界、本机主人、宿主有效且位于可放下马的固定地面。

该入口尚未读取 ER 的原生骑乘区域许可，不能因为原版有限制就假定 MC 命令已经继承。正常马哨必须先接通可信的允许/禁止/未知准入规则；是否提供额外调试绕过单列。马和骑手净空只在实际允许场景中验证，上一轮基于低顶推测的 P2 定性已撤回，见[更正记录](reviews/20261014-architecture-pr-alignment.md)。

集中测试时先准备一个鞍：

```mcfunction
/give @s minecraft:saddle 1
/erbridge mount summon
/erbridge mount status
```

召唤从主人背包借用一个鞍并直接上马。移动和 Space 蓄力跳跃由 MC 原版执行，正常潜行下马；也可在马落地后 `/erbridge mount dismiss`。这是管理员试用入口，尚未加入生存配方、马哨、坐骑成长或自由模式以外的技能授权。

回收归还马当前实际装备，包括用户换入的马铠。背包满、主人不在线/已死亡/已被替换，或有人正从马背包拿着物品时，先下马并保留真实马与装备，等待可归还时清理。带本模块标签的已保存马在加载后走同一归还流程，不扫普通马；真实死亡后的掉落由原版处理，不再重复返还。

摄像机仍使用骑手视角，隐藏法环角色跟随马脚底和落地状态，避免把坐垫高度当成角色落地点。已有地形采样采用管理马的脚底、体宽和步高；普通步行路径保持原值。没有启用备用 `NativeTerrainCollision` 路径，也没有关闭摔伤、马的生命或宿主死亡。

上下马的身份通过 S2C 同步；客户端只能请求释放自己的骑乘。F8、死亡、断连、场景变化、召回和退出触发清理，召回先下马再传送。首轮不承诺骑马乘升降平台，也不支持与 EntitySpeed 等额外移动模块叠加；宿主状态仍作用于骑手，尚未定义毒/减速是否作用于马。

## 调试怪物归属

调试刷兵保留原入口，但清理不再遍历并杀掉整个 debug set。请求前记录现存实例；完成时仅接受同 creator、模板和角色/场景生命周期下，唯一新出现且与结果指针一致的 `(pointer, handle)`。清理前重新确认该身份，取消优先于同帧生成；取消、超时、切图和不完整读取都停止认领迟到结果。

无法确认归属的对象留到地图卸载，取消/超时后本生命周期不再提交新请求。没有向未知取消字段写值，也没有增加来源不明的 hook。共享 creator 没有可用请求 token，因此外部工具同模板、同帧强行覆盖仍无法仲裁；尚未实测与外部刷怪器共载。

## 集中实测清单

1. 配套部署后核对真实版本和安全接管；先完成 B01 的补卢恩、正常升级、发点、购买、退款与重连项目。
2. I 键读取背包，和法环界面核对数量及装备位置；加载/死亡/重进后不保留旧数据。记录是否存在尚未识别的读取布局。
3. 固定平地召唤马，移动、转向、跳跃、正常下马；再观察 F8、场景召回、死亡/重连、满包及马装备界面打开时的归还。先保留默认移动参数。
4. 需要调试怪时检查自身生成与清理，已有外部实例不得因空归属清理被删除；不可确认的竞争行为单列结果。
