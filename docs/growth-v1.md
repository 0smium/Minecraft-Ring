# 交界地成长第一版

本版复用固定 LiquidBounce #3530 原模块与 Pufferfish's Skills 0.19.2 的购买、前置、扣点、退款和存档。角色 Bridge 提供统一授权，不复制一套 Speed、Aura 或 Scaffold 算法。2026-10-14 集中实测已验证 B01/LB 共载、真实等级发点、Speed 学习/退款/执行、预设恢复及生存 Fly 许可授予/撤销；其余能力未因此全部通过。技能图标、菜单久留后误停模块、按解锁过滤 ClickGUI 等问题见[本轮记录](experiments/2026-10-14-growth-equipment-live.md)。下面是当前数据和规则。

## 从开荒到通关

每个角色首次绑定时记录当时真实 ER 等级，以后每升一级获得 1 点。已经绑定的等级起点、历史最高等级和原发点曲线保留；旧 164 级测试角色不会突然收到 163 点。新流程建议在开荒时绑定。回滚等级、死亡、重连不会重复发点。

所有栏目共用同一份 Skills 余额。基础全学共 **76 点**；全部基础加 Speed、Aura 两项精通共 **116 点**；全部满配共 **232 点**。约 100–120 次真实升级可以广修并精通 1–2 项，不要求通关前全部点满。数值是第一版平衡候选，可随实测调整；调整价格须迁移，不能静默改变已有消费。

技能学成只解锁或扩大参数范围，不自动启用模块、不强制把合法偏好提高到上限。只有确实存在的模式/参数才做等级；没有实际可调收益的功能保持单阶。

HUD、ClickGUI 和列入目录的装饰功能免费。挑战模式中未纳入适配的行为模块默认关闭，包括联网 exploit/bypass，不把“没有给它写技能”解释为免费开放。完整免费名单和固定辅助选项以数据目录为准。

## 正常使用与测试预设

绑定后执行 `/erbridge progression challenge`，按 K 打开 Skills；六个栏目在同一树中分区。`/erbridge progression catalog` 查看成本，`status` 查看真实等级、真实点数、测试点数与授权。

测试命令需要本机拥有者、有效角色绑定和挑战模式。`/erbridge progression preset preview` 列出以下构筑，再用 `preset apply <名称>` 应用：

| 名称 | 独立测试额度 / 实际消费 | 用途 |
| --- | --- | --- |
| `starter` | 14 / 14 | 开荒行走、越障、工具与近距标签 |
| `explorer` | 47 / 47 | 机动、搭桥与敌情信息 |
| `fighter` | 78 / 78 | Aura、Velocity 双精通 |
| `journey` | 116 / 116 | 全部基础与 Speed、Aura 双精通 |
| `flight` | 102 / 102 | 高阶段飞行与无限空跳调试 |

应用时先把原学习节点写入恢复日志，再通过 Skills 正式 affordability、前置、阶段和消费接口购买。测试点使用独立 `erbridge:test_preset` 来源；不修改法环等级，不覆盖真实升级额度，不自动启用模块。预设期间新增购买或退款都属于临时构筑。

`/erbridge progression preset clear` 恢复应用前的原节点，并撤掉全部测试点；期间正常升 ER 等级获得的点数保留。必须 clear 后才能切换另一个预设。操作中断会停止授权并保留恢复日志，可以重试 clear；不能借重启把测试点洗成永久点数。

## 旧树与版本

旧树只有六个 Speed/Aura 节点，每阶 1 点。发现旧学习内容时，本版暂停授权并明确提示 `/erbridge progression migrate`。执行此命令会先保存旧节点列表，再通过 Skills 退款，保留真实等级累计额度；不会悄悄给已学节点涨价或清空等级账本。旧列表保存在世界 `data/erbridge/growth/<玩家 UUID>.properties` 的 `legacyNodes`，用于对照和配套存档回滚；在新价格下重新购买需足够点数。

已有世界 `b01.properties` 的 Speed/Aura 上限仍作为保守覆盖，不自动扩大；其余内容来自角色模组 `data/erbridge/ability_catalog.json`。网络使用新 `b01_policy_v2` 通道，旧协议不误读新字段。未知 ID、节点前置破损、价格不符、非预期点源或损坏恢复文件均停止授权。

内容源只有一份目录。运行 `python tools/generate_growth_content.py` 更新 Skills 图谱，`--check` 检查生成物是否漂移。`test_growth_catalog.py` 检查预算、阶段和恢复日志；`test_b01_skills.py` 使用真实固定 Skills 类解析并购买预设；`test_b01_payload.py` 使用真实 MC 缓冲区检查版本化授权包。这些检查不代表游戏内效果已经通过。
