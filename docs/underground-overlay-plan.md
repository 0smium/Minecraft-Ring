# 法环地表 + 同坐标MC地下

2026-10-14，用户进一步明确目标：保留法环原始景观和原生地形，在MC中挖开地表代理后，合成画面显示洞口后由MC生成的石层/洞穴，玩家沿原坐标直接下去。**主线采用这个混合世界方案，不以删除法环原网格、预制固定矿洞或显式传送门为前置。**

本页是源码核查后的实现设计，尚未写入运行代码、生成地下区块或测试洞口画面。0.3.4候选继续保持未部署。

用户随后明确先完成树、花等基础资源：当前已推进[0.3.5地表资源候选](surface-resources.md)，地下方案排在基础资源之后，仍未实现。

## 总体分工

| 部分 | 由谁负责 |
| --- | --- |
| 未开挖的地表景观 | 法环原画面 |
| 地表位置、原生通道的观测 | Bridge只读采样，记录确定/未知证据 |
| 石层、洞穴、矿脉、开挖及矿洞保存 | MC服务端和区块数据 |
| 已挖洞口 | 合成器仅在对应体积内用MC洞内画面覆盖ER地表 |
| 进入地下后的视角与运动碰撞 | MC完整地下场景和自身碰撞 |
| 隐藏法环角色 | 地下期间与MC坐标分离，停驻经验证的地表锚点 |

最终体验目标是普通野外地面可选点下挖。首版先覆盖单层露天地面，再扩展桥下、悬崖、建筑和多层洞穴。无需假设整个法环都只有一层碰撞；复杂区域暂不推断成单一高度。

## 1. 地表边界与地下生成

本项目当前使用只有一层AIR的FlatLevelSource，正常地形由TerrainManager采样填入约两格厚的代理层。换生成器不会自动给已生成的虚空区块补洞穴，因此需要独立的、有预算的地下生成路径。

当前`Column.sample.y`是射线起点；`floorBlock + height/16`才是本次支撑面。玩家走到桥上/楼下会改变这次命中，不能把COLUMNS直接当永久地表高度图。

需要单独持久记录：

- 地图/锚点与生成种子、生成版本。
- 已确认的地表包络；复杂区域的空气区间与未知状态。
- 已生成地下范围、已开挖单元与洞口版本。
- MC拥有空间的边界，覆盖原生采样代理写入权限。

地下洞穴与矿脉以稳定的世界XYZ和种子生成；地表包络只是外壳限制。不能把每列完整原版地形按当地高度独立上下平移，否则邻列洞穴/矿脉会错位。也不能只裁剪原版最终密度：原版自身地表以上是空气，法环高山下方可能因此空掉。

实现应组合复用原版噪声/洞穴、carver与矿物装饰流程，用ER包络替换外层地形约束，并在地表下保留浅覆盖层。读取一个density或getBaseColumn不等于完整原版矿物生成。先做普通干洞、石层、煤铁；含水层、熔岩及地下生态后续加入。现有BridgeBiomes强制Plains，丰富洞穴生态需要相应调整。

生成任务只消费已采样的不可变地表数据，不能在异步区块生成中等待ER。未知列先排队取证，不默认全实心或全空气。生成一次后，玩家挖出的空气与放置物具有最高优先级；重采样不能封洞，重进不能补矿。

同一个MC世界、同一套坐标即可表达这些数据。后台生成的实现方式不应强制玩家走传送门。

## 2. 视觉洞口

现合成器已经有MC世界颜色/深度、手和HUD，以及ER最近表面的深度。开挖要增加局部体积规则，不能全局关闭深度测试。

对一个像素，只有**ER最近可见点落在已挖体积内**，才用MC洞壁/洞底覆盖它；原生人物或物件在洞口之前时继续保留正常遮挡。只判断“视线经过洞口”会把洞前物体一起抹掉。

可选择随MC帧槽传洞口交段深度，或传少量体积并在compositor重建深度点。数据必须匹配实际呈现的poseId：当前选取的是历史帧，不能用最新控制包的相机去重建旧帧。多段挖掘空间不能粗并成一个最小入口/最大出口，中间未挖岩层仍应存在。

还需处理：

- 当前空气alpha=0会继续露出原法环地面。洞口像素必须由MC洞壁、底部或不透明洞内背景覆盖。
- 未挖时，生成石层的近共面顶面不能提前覆盖法环景观；需要地下层显示范围/顶面处理，不能只依赖现有深度bias。
- 眼睛进入地下后带滞回切为MC完整显示，洞沿不反复闪切；第一版先验证入口过渡和回到地表。

单层ER深度没有地形/人物分类，也没有第二层背景。进入挖掘体积内部的原生人物、草丛等可能与待覆盖地面混淆，这是首版真实限制。先在无密集物件的普通地面验证，而不是声称任意场景已正确。

## 3. 玩家与隐藏宿主的分离

用户移动主要由MC碰撞决定，但当前CameraSync还把MC脚底写到`hunterPos`，原生stand_in每帧跟随。地下仍照旧同步会把隐藏角色送入原生未知区域/死亡面；LifeBridge随后会把死亡转回MC。这与洞内是否有MC石头无关。

已有协议的`camPos`与`hunterPos`彼此独立，可作为分离基础。进入地下后保留MC位置和相机，把原生角色停驻在经验证的入口锚点；明确暂停来自该地表替身的普通受击/状态/交互与敌人代理反馈。正常地表的死亡逻辑保留，不能用全局禁死修补越界。

地下伤害由MC场景决定，死亡按统一规则结束地下状态并回到有效法环复活位置；原生换区、退出或锚点失效也必须撤销旧控制状态。F8首版先安全回入口再交回法环，避免旧地下坐标突然再次接管宿主。更远的另一个出口涉及ER流式加载和新地表取证，留到有界首版之后。

新生成的地下石层不应被0.3.4的方块→Havok实验当作地表建筑全部发布。地下无需法环原生刚体；仅在地表建筑模式发布对应方块。原生敌人仍认为原地表存在，首版不会自动掉入MC新矿洞；地下先由MC生物运行。

## 第一实现切片

选一块已确认的16×16或32×32单层露天地面，记录地表包络，在下方生成有界石层和普通洞穴。由玩家正常挖开一格代理表面，显示MC井壁并沿原坐标下到洞穴；封回方块、转镜头、进出洞口和重进存档都保持一致。

首批实现顺序：

1. 地表证据/地下归属/已挖持久化与有界生成；所有terrain写入遵守该归属。
2. 一个短直井的局部深度体积合成，帧槽版本与相机同步。
3. 地下状态与宿主锚点分离，再接普通洞穴/矿脉生成。
4. 集中验证正常挖入、返回、封口、MC死亡/重进；之后扩大自动选址和多层地形。

“随便找一处普通地面挖下去”是方向；第一切片的局部范围是验证边界，不把产品改成固定洞穴采集。
